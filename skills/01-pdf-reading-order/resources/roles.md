# Block roles

| role | Use when | Do not use when |
|---|---|---|
| header | Running head in the top margin | The title of the paper |
| footer | Page number or footer note in the bottom margin | A footnote that is part of the argument; mark those `paragraph` and add uncertainty |
| heading | Section title, larger type or a numbered head | A bold lead-in that continues as a sentence |
| paragraph | Body prose | |
| caption | Starts with Figure/Fig./Table/Tab./图/表 | A sentence that merely mentions a figure |
| table | Row-wise cell text from the table finder | A prose paragraph that happens to contain numbers |
| formula | A short display or inline span dominated by symbols | A sentence that contains one equation among many words; keep it `paragraph` and add uncertainty |
| reference | A bibliography entry, often starting with `[n]` | An in-text citation |

Text is fixed by the extractor. Relabel only.
